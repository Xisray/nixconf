# nixconf
 
Личная конфигурация NixOS.

## Установка
 
Установка выполняется скриптом [`install.sh`](./install.sh) прямо с загрузочной флешки NixOS (без графического окружения). Скрипт:
 
1. Разметит и смонтирует диск(и) согласно `modules/hosts/<host>/disko.nix` (полностью уничтожая текущее содержимое диска).
2. Запросит пароль для пользователя и сохранит его хеш в `/mnt/persist/passwd` (используется опцией `hashedPasswordFile`).
3. Установит систему через `nixos-install`.

### ⚠️ Внимание
 
Скрипт **безвозвратно уничтожает данные** на диске, объявленном в `modules/hosts/<host>/disko.nix`. Перед запуском убедитесь, что указано верное устройство (`device = "/dev/disk/by-id/..."`).
 
### Требования
 
- Загруженное live-окружение NixOS с доступом в интернет.
- Права root (скрипт должен запускаться от `root`, либо через `sudo`).

### Запуск

Одной командой, без клонирования репозитория:
 
```bash
sudo bash <(curl -sL https://raw.githubusercontent.com/Xisray/nixconf/main/install.sh) <hostname> [<commit-sha-или-ветка>]
```

### Аргументы
 
| Аргумент | Обязательный | Описание | По умолчанию |
|---|---|---|---|
| `<hostname>` | да | Имя хоста — должно совпадать с `nixosConfigurations.<hostname>` и каталогом `modules/hosts/<hostname>` | — |
| `<commit-sha-или-ветка>` | нет | Ревизия репозитория, которая будет установлена (флейк подтягивается через `github:Xisray/nixconf/<rev>#<hostname>`) | `main` |

### После установки

После успешного завершения скрипта можно перезагружаться:
 
```bash
reboot
```
